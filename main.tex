% Here goes the abstract
\begin{abstract}
%Why
~\textbf{Purpose:} Adaptive Systems, realized by \ac{COP}, enable software systems to modify their 
behavior at run time, in response to the execution context. Adaptations occur by means of a 
(de)activation mechanism that dynamically declares the scope of a given functionality. Writing 
programs in a \ac{COP} fashion enhances modularity and expressivity, however, it also poses 
challenges when validating the execution of the program. Testing \ac{COP} programs requires 
programmers to reason about the immense space of possible state values, and how those affect the 
flow of the program by identifying the components that are activated or deactivated at a given point in 
time.
%What
\textbf{Method:} 
There is an ongoing research effort to create tools and frameworks to improve the correctness of 
\ac{COP} programs, however, no usage of software verification tools have been found to date on this 
area. We propose a framework based on Refinement Types to formally verify the consistency and 
completeness of adaptations. 
\textbf{Results:} 
We use a case study of a graphical editor, illustrating how to reason about \ac{COP} programs using 
refinement types, focusing the formulation of properties regarding the interactions between active 
adaptations. The result of this study is a verified assessment of the use of refinement types to validate 
the consistency and completeness of dynamically adaptive systems.
\textbf{Conclusion:} 
With this work we illustrate the benefits of software verification techniques for \ac{COP}, by means of 
Refinement Types.
\end{abstract}

% Research highlights
\begin{highlights}
\item Implement a simple \ac{COP} library for Scala based on Predicated Generic Functions.
\item Using the developed library, implement a graphical editor taking Gueze as a reference.
\item Integrate Stainless with the \ac{COP} library to write an specification that establishes the expected activation behavior and interactions between the components of the application.
\item Identify the main bugs in that were encountered due to inconsistent layer interaction, and discuss how Refinement Types can be used to detect them and fix them.
\item Formal method to assure completeness of dynamic adaptations.
\item Implementation of a Context-oriented language with refinement types
\item Implementation of a medium size case study
\end{highlights}
